# Perch app — landing + dashboard + session API (one app)

**Stack (per project rules): TanStack Start (not Next.js) · Panda CSS · Ark UI / Park UI.**
One app serves everything:
- `/` — the marketing landing page
- `/dashboard` — configure your widget, copy the embed snippet
- `/api/perch/session` — mints the ElevenLabs signed URL (key stays server-side)

## Run it (npm works on your machine; it's blocked in the build sandbox)
```bash
pnpm install          # or npm install
pnpm codegen          # panda codegen -> generates styled-system/  (REQUIRED first)
pnpm dev              # http://localhost:3000
```
Set env for live voice: `ELEVENLABS_API_KEY`, `PERCH_DEFAULT_AGENT_ID`.

## Styling rules enforced here
- **No inline styles** — `eslint.config.js` errors on any `style={{…}}`. Use Panda
  `css()`, recipes, or components.
- **Components over inline** — `components/ui/button.tsx` (Panda cva), `GlassPanel`
  (recipe), `LiquidOrb` (recipe). Add more Park UI components with the Park UI CLI.
- Design system lives in `panda.config.ts` (Park UI preset + iris/aqua tokens,
  keyframes, `glassPanel` / `liquidOrb` recipes).

## Honest notes (I couldn't run this in the build sandbox — npm blocked)
- **Run `panda codegen` first** — the `styled-system/*` imports don't exist until you do.
- **Pin versions.** `package.json` versions are indicative; TanStack Start + Park UI
  move fast. If the scaffold fights you, generate a fresh TanStack Start app with the
  official CLI, add Panda + Park UI via their init flows, then drop in this repo's
  `panda.config.ts`, `app/components`, `app/routes`, and `app/lib`.
- **Server-route API:** TanStack Start renamed the server-route helper across versions
  (`createServerFileRoute` / `createAPIFileRoute`). The handler body in
  `app/routes/api/perch/session.ts` is correct; adjust the wrapper to your version.
- `routeTree.gen.ts` is generated by the TanStack Router plugin on first `dev`.

## Relationship to the rest of the repo
- The **embed widget** (`perch/packages/embed/perch.js`) stays vanilla/buildless by
  design (Shadow DOM, one script tag) — the one place inline styles are required.
- This app is the product surface (landing + dashboard). It supersedes the static
  `perch/apps/site` demo for the real thing.
