# Base Cover Letter — Rich Tillman

## How to tailor (2 minutes, 3 swaps)
1. [HOOK] — one specific, true line about the company/product (their launch, mission, a problem you can speak to).
2. [FIT] — 1–2 sentences tying your background to THIS role's top requirement.
3. [OUTCOME] — the result you'd help them get. Also set [Company], [Role], [Hiring Manager].
Keep it to ~250–300 words. Cut a sentence before you add one.

---

Dear [Hiring Manager / Hiring Team],

For [Role] specifically: [FIT — tie your experience to the role's core need]. I'm at my best where ambiguity is high and ownership is real — I've done zero-to-one at five startups and shipped ForgeKit solo — and I work AI-native by default, authoring MCP tooling and using Claude Code and Cursor to move fast without sacrificing quality.

I'd welcome the chance to talk about how I can help [Company] [OUTCOME]. Thank you for your time and consideration.
