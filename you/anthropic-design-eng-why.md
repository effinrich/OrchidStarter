# Why Anthropic? — Design Engineer, Web (Creative Studio / Brand Web) — application answer
Target: 200-400 words. Status: working draft, refined from Rich's own dictated first pass per Anthropic's candidate AI guidance (draft yourself, Claude refines).

I really love this stuff, and I have for a long time. Fifteen years in production, longer if you count freelancing before that — but the real turning point was 2016, when React clicked for me, and Storybook landed in almost the same moment. A few years after that, Nx monorepos hit me as a second force multiplier: component-driven development, design systems, monorepo architecture, and code generation all started compounding together instead of living as separate concerns.

For the last five years specifically, my actual work has centered on that same collaborative loop — design, engineering, and automating the connection between them with code. Long before I saw the term used anywhere else, I'd concluded on my own that design and engineering had to be tightly fused to build something that really works, and I privately started calling myself a design engineer — my own label, nothing external prompting it. Watching that term turn up recently on other people's resumes and job descriptions, including this one, has been genuinely surreal: not validation I went looking for, just the industry catching up to a name I'd already given myself.

What Anthropic represents to me is the next force multiplier in that same line, and one of the companies most responsible for the shift itself. Work that used to take a dedicated team months — turning a Figma file into a typed, production-ready component, keeping a design system self-consistent as it scales — is becoming radically more accessible with AI in the loop. I've already been building toward that: ForgeKit, my open-source CLI and MCP server suite bridging Figma to React to Storybook, has 5,700+ npm installs from real teams. I author MCP servers — the protocol you created — as part of my daily practice, not as a novelty.

That's the actual pull: I want to be genuinely involved in pushing that shift forward, at the company positioned to champion it in a real way — not just using the tools Anthropic ships, but helping build what comes next.
