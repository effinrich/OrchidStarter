# Why Anthropic? — application answer (~235 words)

The honest answer is that I've been building toward Anthropic without planning to. I author MCP servers — the protocol you created — and use Claude Code every day, not as novelties but as how I actually ship. My open-source suite, ForgeKit (5,700+ npm installs), exists to make design systems legible to AI agents. So your work isn't something I admire from the outside; it's the ground I already stand on.

The People Products mission is where it gets personal. I've been the hiring manager on the other side of these problems — handed Greenhouse to hire two frontend engineers, I ended up rewriting the job description and re-authoring the technical assessment myself, because getting evaluation right is the whole game. I've built onboarding that ramped engineers to production React in a month, and at Mercor I designed rubrics scoring AI output on hard engineering tasks. Identifying talent, assessing it honestly, ramping it fast — I keep circling that problem. Doing it with Claude in the loop is the most interesting version of it I can imagine.

The mission matters plainly, too: if AI is going to reshape how people work, I'd rather build it somewhere that treats "reliable, interpretable, and steerable" as the point, not an afterthought.

And the shape of the work — high autonomy, real ownership, prototype-to-production in days, talking straight to the people I build for — is exactly how I do my best work.
